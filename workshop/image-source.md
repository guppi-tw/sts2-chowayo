# サムネイルの出典

Slay the Spire 2 public-beta v0.113.1のレアカード `WAH_CHO_KI` を、Chowayo v0.3.1を有効にしてゲーム本来のカード描画で撮影しました。
日本語の表示名は「チョ・ワー・ヨ」です。未強化のカードを使用しています。

- 撮影日 2026年11月17日
- `image.png` は512×512のPNG
- 背景は単色、カード名・枠・イラスト・コスト・効果はゲームの表示そのまま
- 画像生成AIによるカードの描き直しや、文字の後付けは行っていません
- カードの画像・デザインはMega Critのゲーム素材です

## 再撮影

ゲームを終了し、動作確認済みのChowayoを手動配置した状態で実行します。

```sh
python3 workshop/capture-card.py
```

実ゲームを一時プロフィールで起動し、ゲームの `NCard` を512pxと1024pxの描画領域に表示してPNGを保存します。
元のセーブと導入済みMODは撮影後にハッシュで照合し、撮影用MODを取り除きます。
生成先は `.artifacts/chowayo/card-capture-*/` です。512pxの画像を `workshop/image.png` に配置します。
