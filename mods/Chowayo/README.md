# チョワヨ

Slay the Spire 2のフールの「キ」を「ヨ」に変える独立したMOD。英語は Ki → Yo に変えます。
3音のカード名は「チョ・ワー・ヨ」、2音のカード名と説明中の列挙はチョ・ワー・ヨの順に揃えます。

| 元の名前 | 変更後 |
| --- | --- |
| キの旋律 | ヨの旋律 |
| キ・ホップ | ヨ・ホップ |
| ワー・チョ | チョ・ワー |
| ワー・キ | ワー・ヨ |
| チョ・キ | チョ・ヨ |
| ワー・チョ・キ | チョ・ワー・ヨ |

ほかのキ系カード、関連パワー、ポーション、レリックの説明にも反映します。
ワーとチョの旋律名、カードの効果・数値・内部IDは変わりません。
英語の複合カードは Cho Wah、Cho Yo、Wah Yo、Cho Wah Yo とし、説明中の列挙も同じ順にします。
ほかの翻訳済み言語も、元の言語の表記を残して同じ順に揃えます。日本語を含む15言語が対象で、未翻訳の項目は英語の読み込みに追従します。
ゲーム本体のファイルやセーブデータを書き換えず、翻訳テーブルの読み込み時に名称を差し替えます。
Bilingual Spireと併用した場合も、両側の表示に適用します。

v0.4.1はpublic-beta v0.114.0のHP減少処理の変更に対応しています。ゲームの必要バージョンはv0.114.0以降です。
ダメージ予測中は被弾ボイスを鳴らさず、実際のHP減少時だけ1回再生します。ロシア語の「ワ」の表記も現行の翻訳に揃えました。
v0.4.2では「ヨ・ヴァース」のカード・パワー説明3箇所に残っていた「ワー」か「チョ」を、「チョ」か「ワー」に揃えました。

## 導入

`Chowayo.dll` と `Chowayo.json`、`icons` フォルダをゲームの `mods/Chowayo` に置き、ゲームを再起動します。
Macの配置先は `SlayTheSpire2.app/Contents/MacOS/mods/Chowayo` です。
「設定 → MOD設定」で「チョワヨ」を有効にしてください。
削除する場合はゲームを終了して `Chowayo` フォルダを取り除きます。

## ビルドと確認

リポジトリのルートで実行します。.NET 9とSteam Mac版のゲームが必要です。

```sh
dotnet build mods/Chowayo/Chowayo.csproj -c Release -t:DeployMod
python3 mods/Chowayo/smoke-test.py
python3 mods/Chowayo/smoke-test.py --audio
```

テストはSteam接続を切った実ゲームをヘッドレスで起動し、単独とBilingual Spire併用を確認します。
一時プロフィールを使用し、終了後に既存の非Steamプロフィールを復元して、Steam用・非Steam用のセーブのハッシュを照合します。
ゲームが起動中の場合は実行しません。テスト終了時にはRelease版を配置します。
外付けSteamライブラリは `--game-dir "/path/to/Slay the Spire 2"` で指定できます。
`--mod-settings "/path/to/settings.save"` で、その設定の有効MODと読み込み順を一時プロフィールに再現できます。

## 旋律アイコン

v0.4.0では弓の上に出る旋律アイコンをスピキの顔に変更します。
チョは青、ワはピンク、ヨはオレンジです。元のサイズ・旋律判定・説明・発光・出現と移動のアニメーションを維持します。
音声の有無とは独立して動作します。`icons/speaki.png` がない場合はゲーム本来のアイコンを表示します。
元のアイコンに戻すときは、ゲームを終了して配置先の `icons` フォルダを取り除きます。
素材の出典と加工内容は [画像の記録](docs/third-party-images.md) にまとめています。

2026年11月20日、Mac版v0.113.1で単独・Bilingual Spire併用の両方が終了コード0でした。
3色の透過アイコン、元の当たり判定・旋律ID、出現・移動アニメーションを確認しています。
実際の戦闘でも3色を表示し、4枚のカード使用から勝利まで終了コード0、約59.5fpsで完了しました。
既存のSteamセーブは変更なし、非Steamセーブはテスト後にハッシュ一致で復元しています。

v0.2.0の音声もMac版v0.113.1で単独・二言語MOD併用の両方が終了コード0で成功しました。

## 音声素材

v0.2.0ではローカル検証用にスピキの音声を追加できます。

- チョ・ワー・ヨの旋律で、それぞれ短い「チョ」「ワ」「ヨ」を再生します。
- 「チョ・ワー」と「チョ・ワー・ヨ」は、演出と音声をチョ→ワ→ヨの順にします。カードの効果と旋律判定は元のままです。
- フールがHPを失うと「アーウ」、死亡時には「ウアア」を再生します。完全にブロックした攻撃では悲鳴を鳴らしません。
- v0.3.0では、フールの戦闘勝利に `victory.wav`、敗北の結果画面に `defeat.wav` を使えます。ランの放棄では敗北ボイスを鳴らしません。
- ゲームのマスター音量・効果音量に追従します。

`local-audio` に `cho.wav`、`wa.wav`、`yo.wav`、`hurt.wav`、`death.wav`、`victory.wav`、`defeat.wav` を置いてビルドすると、ゲーム側の `mods/Chowayo/audio` にコピーされます。
旋律音声3つが揃わない場合は元の旋律音と演出順になります。被ダメージ・死亡・勝利・敗北の音声は個別に省略できます。
音声だけを元に戻すには、ゲームを終了して配置先の `audio` フォルダを取り除きます。

今回取得・加工した音声はGit管理から除外しています。音声入りZIPはGitHub ReleasesとSteam Workshop向けに作成できます。
出典と加工内容は [音声の記録](docs/third-party-audio.md)、配布に関する調査は [音声素材の利用条件](audio-guidelines.md) を参照してください。

## 音声プレビュー

```sh
python3 mods/Chowayo/preview/build-preview.py
```

`.artifacts/chowayo/voice-preview.html` をChromeで開きます。サーバーもネット接続も不要です。

- 旋律・被ダメージ・死亡・勝利・敗北の5用途を同じ画面で選択できます。
- 13種類の素材を切り替え、チョワヨの歌3系統は1回目・2回目・最後のフレーズを選べます。
- 波形の境界はドラッグ、矢印キー、秒数入力で調整できます。旋律の隣り合う区切りは連動します。
- 元音声、切り出し後、現在のローカルMOD音声を比較できます。連続再生は隙間なし・ゲームの通常速度に近い0.5秒間隔の2通りです。
- WAV保存はモノラルPCM16・48kHzで、選択したフェードを反映します。試聴音量はWAVには反映しません。
- 「設定を書き出す」で出典と切り出し位置をJSONに保存します。ページを閉じると未保存の調整は失われます。
- 別のローカル音声も読み込めます。ファイルは外部送信しません。

候補の区切りは波形に基づく仮設定です。素材の聞こえ方や音節の切り方は試聴して選んでください。
HTML内の操作だけではゲーム内の音は変わりません。保存したWAVを `local-audio/` に配置して再ビルドすると反映できます。
元の録音と生成HTMLは `.artifacts/` 内にのみ置き、Git管理から除外しています。

2026年11月17日のv0.3.0確認では、単独・Bilingual Spire併用とも終了コード0でした。

## パッケージ作成

```sh
python3 mods/Chowayo/package.py
python3 mods/Chowayo/package.py --with-audio
```

1つ目は音声なし版、2つ目は7音声を収録した版です。
`.artifacts/chowayo/packages/` にZIPとSHA-256を保存します。
Release版のMOD、導入手順、収録ファイルのハッシュを同梱し、音声入り版には出典・加工記録も含めます。
ゲーム本体のDLL、セーブ、設定、ビルド用ファイルは入りません。作成時にZIPの展開内容と元ファイルの一致を確認します。
